# COA & Batch Records

Official COA library: [https://sulanpeptide.net/coa/](https://sulanpeptide.net/coa/)

Sulan Peptide displays selected COA and batch record snapshots for buyer-side documentation review.

## What the records may include

Available records may include:

- Product name
- Purity result
- Batch reference
- Janoshik task number
- Unique key
- Report snapshot

## Why batch documentation matters

Batch-level documentation helps buyers compare product records with available third-party testing information. A product name alone is not enough for serious documentation review; product identity, purity, batch reference, task number, and unique key details can all be relevant.

## Janoshik testing context

Janoshik is widely recognized among peptide buyers as a third-party analytical testing laboratory. Sulan Peptide presents Janoshik-tested records where selected batches have available reports. These records are presented as third-party batch documentation, not as an official regulatory certification for the full product catalog.
